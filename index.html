行業結構痛點：為什麼停車場持續失血？

營收鎖死、車流壅塞、決策靠猜——三重結構性困境。

📉

固定費率無法反映真實供需，尖峰「滿場拒客」等於白白讓出溢價空間；離峰空位閒置，折舊照付。

📊 離峰利用率僅 23%
🚗
車流壅塞與體驗崩壞

大型活動期間缺乏價格引導，車流集中湧入，平均找位 30+ 分鐘，大量客訴與負評。

📊 活動日客訴量 5 倍
🎲
決策靠直覺而非數據

管理者憑「經驗感覺」手動調費率，缺乏科學依據，錯過最佳定價窗口或幅度失當。

📊 最佳窗口命中率 < 15%

企業級防禦防線

停車場涉及車牌個資與費率公正性——資安與合規是落地關鍵。

本地化部署 + 車牌隱私
  • 支持 100% On-Premise，營收數據不上雲
  • 車牌即時雜湊化（Hashing），不儲存原始車牌
  • 符合個資法，支持刪除權（Right to Erasure）

  • 硬性上限：費率不超過主管機關公告天花板
  • 硬性下限：不低於營運成本底線
  • Agent 無權自主執行，管理者審批才上線
🧱
Prompt Injection 防禦
  • Llama Guard 護欄攔截惡意輸入
  • 防止偽造活動資訊誘導異常費率
  • Agent 輸出偏離歷史分佈則自動凍結
📋

  • 費率變動全程留存稽核軌跡
  • 公開費率邏輯，消費者可查詢計價依據
  • 避免歧視性定價，確保公平性

📐 實務部署：動態定價雙層架構

PoC 展示為加速演示採用即時觸發。實務部署採用雙層策略：事件層（即時）偵測活動/天氣等突發事件自動推演；基礎層（日/週）依據歷史車流模式設定常態費率曲線。兩層協作確保既能捕捉突發溢價機會，又有穩定的基礎營收模型。

❌ 場站系統老舊

多數停車場仍用 20 年前閘門系統，無 API 可串接。

✅ 輕量疊加方案

Phase 1 僅更新電子看板+APP 通知，不動既有閘門。

❌ 消費者抗拒漲價

動態定價 = 「AI 坑錢」，公關風險大。

✅ 透明 + 獎勵框架

費率邏輯公開可查，搭配早鳥折扣讓車主感受「省錢」而非「被漲」。

❌ 法規限制費率上限

部分縣市公告停車費率天花板，動態空間有限。

✅ 合規內最佳化

在法定天花板內做離峰折扣（向下空間大），主攻填滿率而非漲價。

❌ 活動資訊不即時

售票平台未必開放 API，臨時加場/取消難以追蹤。

✅ 多源融合 + IoT 驗證

爬蟲+社群+IoT 車流即時驗證，不依賴單一數據源。
